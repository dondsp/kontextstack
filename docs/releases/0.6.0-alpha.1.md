## Evidence and boundary

68 tests pass, including generated runtime test execution, real Apache routing,
encoded redirects, missing-asset/API refusal, symlinks, unsafe inputs, dependency
compatibility, exact approval and legacy upgrades. The generated runtime suite
also covers startup configuration, readiness failure, methods, assets and logs.

Browser smoke verifies root/navigation, direct-route reload, narrow viewport and
keyboard focus. Source/privacy audit, doctor, mature source installation
verification, package dry-run and isolated tarball installation/lifecycle smoke
pass. Public CI must pass on Node 20 and 22 for the final release commit. The
tag-triggered release check must pass before npm upload.

The package and all modules remain filesystem-only. No module command runs, no
network permission is granted, and writes remain in module-owned namespaces.
KontextStack has no provider, production, database, deployment or Git authority.

Source paths/revisions, exact working-tree snapshot hashes, removals and
adaptations are recorded in IMPLEMENTATION_BASELINE.md, DOMAIN_STATIC_PORT.md
and NODE_RUNTIME_PORT.md under docs/architecture. No private project repository
or production data is included.

The GitHub prerelease records the exact merged commit and tarball integrity.
The reviewed tarball is installed and verified before and after publication.
Local publication does not claim a hosted-build provenance attestation.

## Not included

MySQL migration tooling and auth adapters, deployment/operations implementation
kits, full composition/recovery scenarios, ContextKraft guide activation and
production deployment remain outstanding. Those modules retain planning-only
behavior. Alpha software is for evaluation and receives no production authority.

## Installation and upgrade

```sh
npm install --global kontextstack@0.6.0-alpha.1
kontextstack about
kontextstack doctor
kontextstack modules available
```

Inspect and preview the selected module version, approve the exact preview,
apply, then verify. Open the installed START_HERE.md and CODEX_PROMPT.md.
Installing a kit does not adapt application code or complete provider setup.
Resolve customized-file conflicts by reviewed reconciliation; do not delete
lock history to bypass them.

To return the CLI to the stable channel, explicitly install kontextstack@0.5.1.
This does not remove installed kits or perform a project downgrade. Restore
project-owned records only through the project's reviewed recovery procedure.
