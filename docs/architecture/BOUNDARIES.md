# Product Boundaries

ContextKraft owns project understanding, context refresh, guided handoff, and
the user-facing `/guide` experience.

KontextStack owns local validation, read-only inspection, module compatibility,
deterministic preview, exact approved application, verification, and project
provenance.

The user's project repository owns implementation, production records, Git
history, deployments, and ongoing Codex work.

KontextStack itself has no authentication system, database, cloud storage, AI
provider, hosted account, telemetry, background synchronization, DNS authority,
deployment authority, or Git write authority.
