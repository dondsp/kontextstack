# Adaptation

Each target records its exact public HTTPS origin. The final check compares
static root bytes with staged index.html, and Node health must expose a minimal
release field equal to the selected commit. Record the Node healthPath without
a leading slash and adapt that field into the canonical runtime. This detects a
healthy previous deployment. Add representative route and signed-out auth checks
to policy.smoke. Byte-transforming hosts or non-root static mounts require a
separately reviewed exact-asset adaptation before use.

Adapt deploy.yml.template into .github/workflows/deploy.yml only after inspecting the repository. Copy templates/artifacts.mjs, deliver.mjs and release-cli.mjs plus checks/smoke.mjs into scripts/release/. Adapt release-policy.json using explicit exact file lists for the selected static, node or split target. Keep revision null in the committed policy; the CLI binds the manifest to the explicitly selected current Git commit, avoiding a self-referential commit. Set check/build scripts to the canonical project checks and deterministic build. npm ci uses the lockfile with hooks disabled; explicitly review any required build/native hooks before a scoped adaptation. Actions are pinned to reviewed immutable commits. The workflow is manual dispatch on the approved branch, with a protected environment, read-only token, no persisted checkout credentials and non-cancelling concurrency. Configure required reviewers and branch restrictions in GitHub first; REVIEWERS_CONFIGURED is a local checklist acknowledgement, not proof of provider protection. If the account cannot enforce reviewers, retain the manual operator path. Produce the artifact locally against the selected revision; record its exact manifest integrity before dispatch. The CI delivery rejects a different build, destination or identity. For Node, record dependenciesInstalledFor as the SHA-256 of package-lock.json only after separately verifying the host dependencies. Dependency changes pause delivery for an approved host install; never install packages over an active app without the reviewed runtime procedure. Optional tmp/restart.txt is a deliberate Passenger restart effect included in the exact approval, sent only after every selected target uploads. Credentials enter only the upload step, go to curl over stdin and are never printed. TLS certificate checks remain enabled. No provider, database, bootstrap, restore or arbitrary command is invoked by KontextStack.
