# Publish a static site to cPanel

This kit installs reference files and procedures. It never builds, uploads,
deletes, deploys or operates a provider account.

Confirm every selected feature works as public static files. Private credentials,
server authorization, persistent server data and SSR need a separately reviewed
backend. Select the smallest needed capabilities; do not install a database or
authentication for a static site without evidence.

Read decision.json, evidence.json and implementation.json; preserve the older
release.json and RUNBOOK.md records. Follow IMPLEMENTATION.md and give Codex the
CODEX_PROMPT.md from the actual project. Provider setup is separately approved.
