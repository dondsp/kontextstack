# Codex implementation brief

Work only in the selected project repository. Read its AGENTS.md and architecture
documents first. Inspect the actual source, build, routes, hosting records and
Git state. Read this module's decision.json, evidence.json, implementation.json,
START_HERE.md and ROLLBACK.md before edits.

Separate confirmed facts, assumptions, missing evidence and conflicts. Ask only
for choices that change the outcome. Adapt the installed kit to the existing
architecture; do not replace working files or create a second runtime blindly.
Preserve unrelated changes and provider-managed paths. Templates are references,
not overwrite instructions. Edit only the approved project scope.

Never print, copy or commit secret values, .env contents, session URLs, customer
data or production rows. Keep evidence non-secret and review screenshots before
retaining them. Run the project's required local checks and the selected kit
checks after inspecting their code. Report exact commands, outcomes and gaps.

Pause for separate explicit approval before any provider, production, destructive
or data-changing action. Name the exact target, owner, effect, expected result,
verification and rollback. Installing this kit grants none of that authority.

Record installed, implemented, locally-verified, provider-configured, deployed,
migrated, production-verified and owner-accepted separately. Update project-owned
release and recovery records. Retain evidence references and mark deferred work
as deferred, never as passed. Report every remaining manual/provider action.
