# Add or adapt a cPanel Node runtime

Use this kit only when server-owned behavior is required. It installs inert
reference files; it does not start a server, create a hosting application, set
provider variables, install dependencies or restart production.

Inspect the actual repository first. Read implementation.json and complete
decision/evidence records with non-secret references. Preserve prior runtime.json
and RUNBOOK.md choices. An existing framework keeps its own server and router.
A greenfield no-auth fixture can adapt the minimal reference in IMPLEMENTATION.md.

Run reviewed local checks before PROVIDER_SETUP.md. Provider actions require
separate exact approval. Follow VERIFICATION.md, keep ROLLBACK.md ready and give
CODEX_PROMPT.md to Codex inside the selected project repository.
